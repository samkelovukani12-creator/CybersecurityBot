# Description of Cybersecurity Chatbot

This C# console-based Cybersecurity Chatbot designed to provide users with simple and useful information about staying safe online. The chatbot uses object-oriented programming, inheritance, a 2D array for storing cybersecurity tips, randomised responses, input validation, and keyword recognition to respond to user questions.

Users can ask about topics such as **password security, phishing, malware, hacking, two-factor authentication, social media safety, public Wi-Fi, antivirus software, and online privacy**. The chatbot also provides random cybersecurity tips and allows users to end the conversation by typing `exit`, `quit`, or `bye`.

## Technologies Used

* C#
* .NET Console Application
* Object-Oriented Programming (OOP)
* 2D Arrays
* Inheritance
* Randomisation
* Input Validation
* Keyword Recognition
